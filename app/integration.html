Integrations

Create and link mitigation tickets in Jira, Azure DevOps, GitHub, GitLab or OpenProject. The ticket state drives the mitigation status in the risk model.

01

Supported Systems

  • Jira Cloud — connection test, project and issue type, create and link tickets
  • Azure DevOps (Azure Boards) — create and link work items and follow their state; the token is bound to your organization
  • Preview — usable now, confirmed against live instances over time: Jira Server / Data Center, GitHub Issues, GitLab Issues, OpenProject
  • Polarion — planned
02

Workflow

  • Select mitigations from the risk table and export as tickets
  • Ticket includes: threat description, risk level, proposed mitigation, verification criteria, DFD reference
  • Ticket states sync when the Risk tab opens or on Sync ticket status
  • The mitigation status follows its ticket in both directions; a ticket closed as won't fix marks the mitigation rejected with the ticket as reason
  • The token stays in the OS keychain, bound to the tracker's address — a project file can never point it elsewhere
  • Your account is not written into the project file — every team member uses their own
03

Azure DevOps Setup

  • In Integration choose Azure DevOps and enter https://dev.azure.com/<organization>
  • Use a personal access token with Work Items: read & write
