Integrations

Export mitigations as tickets to Jira, Azure DevOps, or GitHub Issues. Receive status updates when tickets are closed and reflect them back in the risk model.

01

Supported Systems

  • Jira — one Integration tab: connection test, project and issue type, create and link tickets
  • Azure DevOps — returns with a later release (not connected in 0.16)
  • GitHub Issues, Polarion (planned)
02

Workflow

  • Select mitigations from the risk table and export as tickets
  • Ticket includes: threat description, risk level, proposed mitigation, verification criteria, DFD reference
  • Ticket states sync when the Risk tab opens or on Sync ticket status
  • The mitigation status follows its ticket in both directions; a ticket closed as won't fix marks the mitigation rejected with the ticket as reason
  • The API token stays in the OS keychain, bound to the Jira address — a project file can never point it elsewhere
  • Your Jira e-mail is not written into the project file — every team member uses their own account
