App / 08

Documentation Export

Generate audit-ready documentation from the live TARA model. Every export includes full traceability from mitigation back to the originating DFD element.

01

Export Formats

  • PDF — formatted report suitable for submission to auditors or customers
  • HTML — interactive report with cross-links
  • AsciiDoc — source for integration into product documentation
  • Markdown — GitHub-compatible, CI-friendly
  • StrictDoc (.sdoc) — structured requirements-engineering format for toolchains built around it
02

Traceability

  • Every mitigation links to the threat it addresses
  • Every threat links to the DFD element and asset it originates from
  • Every verification links to the mitigation it validates
  • Norm references included per mitigation (IEC 62443 CR, ISO 21434, CRA article)
03

Headless generation (CLI)

  • The same Markdown, AsciiDoc, HTML, PDF and StrictDoc output can be generated from the command line, without the desktop app or Electron — built for CI/CD pipelines (e.g. Jenkins) and Docker/Podman containers
  • Reads a saved .tara.json project file directly; no project needs to be open in the UI
  • Distributed as a standalone .deb package, decoupled from the desktop installer
