User Guide

TARAflow App

Step-by-step guide to each module — from project setup through DFD modeling, asset definition, threat generation, risk assessment, and documentation export.

Modules

All Sections

01

Overview & Setup

Project initialization, context, criticality, and regulatory tags.
02

Hazard Identification

Optional safety analysis: Bowtie modeling, cyber-reachability triage, import from existing safety records.
03

DFD Modeling

Draw.io integration, element types, Trust Boundaries, PhysicalBoundary, ChipBoundary.
04

Assets

Asset inventory, CIANAAA goals, impact factors, element-to-asset relationships.
05

Threats

STRIDE generation, per-element and per-interaction, manual threats, review workflow.
06

Attack Tree

Attack-path threat modeling, feasibility per ISO 21434 Annex G or IEC 62443, synced into risk.
07

Risk Assessment

Likelihood scoring, risk matrix, MoSCoW prioritization, before/after comparison.
08

Documentation

Export to PDF, HTML, AsciiDoc, Markdown, StrictDoc — full traceability included, headless CLI available.
09

Audit Trail

Versioned change log, sign-off workflow, re-assessment triggers.
10

Integrations

Jira, Azure DevOps, GitHub Issues — mitigation ticket export and status sync.
