# Contributing to TARAflow

Thanks for your interest in TARAflow! 🎉

## Current status

> **TARAflow is in pre-release.** The codebase is being developed privately and will be transferred to this repository once it reaches a stable milestone. **There is no source code here yet**, so code contributions (pull requests) are not possible at this stage.

That said, early input genuinely shapes the public release — and there are useful ways to get involved right now.

## How you can help today

### 💡 Share feedback on the methodology

TARAflow is opinionated about *how* threat analysis and risk assessment should work — graph-based traceability, DFD-driven STRIDE generation, `impact × likelihood` scoring, native safety–security integration. If you work with TARA in OT, embedded, automotive or medical contexts, your perspective is valuable.

[Open a discussion-style issue](https://github.com/TARAflow/TARAflow/issues) to:

- Suggest a feature or workflow you'd want supported
- Describe a real-world use case the tool should handle well
- Point out a standards interpretation worth getting right (IEC 62443, ISO 21434, CRA, EN 50742)
- Flag interoperability needs (import/export with existing tooling)

### 👀 Follow along

**Watch** or **star** the repository to be notified when the code lands and the first release is tagged.

## What happens after the code transfer

Once the codebase is public, this document will be expanded with:

- **Development setup** — prerequisites, install, build and run instructions
- **Project structure** — how the codebase is organized
- **Coding conventions** — including the project rule that *all code, comments and commit messages are written in English*
- **Pull request process** — branching, review and merge expectations
- **Issue templates** — for bug reports and feature requests
- A **Code of Conduct**

## Reporting issues (once code is available)

When the tool is published, good bug reports will include:

1. What you expected to happen
2. What actually happened
3. Steps to reproduce
4. Your environment (OS, version)
5. Relevant logs or screenshots
