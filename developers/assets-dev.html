Asset Model

The asset model uses a discriminated union for typed asset properties and an auto-derivation engine for CIANAAA security goals.

01

AssetProperties

  • Discriminated union on assetType: data | function | system | physical | service | process
  • Each type carries type-specific properties (e.g. DataAsset: dataClassification, encryptionRequired)
  • Common base: id, name, description, linkedElementIds[], securityGoals[] (CIANAAA)
  • Impact factors: financial, operational, regulatory, recoverability — drive initialImpact
02

CIANAAA Derivation

  • Each asset has securityGoals[]: { type: CIANAAAGoal, level: CIANAAALevel }
  • level ≠ none → goal is active → contributes to STRIDE category set via CIANAAA_TO_STRIDE
  • maxLevel() across active goals for a STRIDE category → initialImpact on threat
  • Asset-to-element sync: bidirectional — element changes propagate to asset linkedElementIds
