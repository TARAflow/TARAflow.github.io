Architecture

TARAflow is an Electron desktop application with a React/TypeScript frontend. The codebase is organized into feature modules with strict import boundaries.

01

Stack

  • Electron (main process) — native OS integration, keytar for credential storage, file I/O
  • React 18 + TypeScript — UI, MUI DataGrid, draw.io iFrame integration
  • Vitest — unit tests for geometry, generators, catalog service
  • i18next — runtime i18n with EN/DE namespaces
  • draw.io (diagrams.net) — embedded as iFrame for DFD editing
02

Feature Boundaries

  • features/dfd — DFD modeling, draw.io bridge, DFDGraphReference
  • features/threats — threat generation, catalog, risk, attack tree
  • features/assets — asset model, CIANAAA, impact factors
  • src/shared — all types shared between features (DFDElementReference, StrideCategory, etc.)
  • Rule: features/threats and features/dfd must NEVER import from each other
