Audit Trail

Every change in TARAflow is logged with timestamp, actor, action, and a brief summary. The audit trail supports sign-off workflows and re-assessment governance.

01

Audit Log Entry

  • Entry ID and ISO 8601 timestamp
  • Actor role (Name/Team/Role)
  • Action: create | update | delete | approve | link | re-assess
  • Object: DFD element, Asset, Threat, Risk, Measure — with ID
  • Version: old → new
  • Change summary — brief description
  • References: Ticket, Commit, Validation link/hash
  • Integrity (optional): signature/checksum
02

Sign-off & Governance

  • Risk owner sign-off per threat table
  • Won't-fix decisions require documented justification
  • Re-assessment triggers defined per project: architecture change, new CVE, regulatory change, annual review
  • Governance board output links back to audit entries for traceability
