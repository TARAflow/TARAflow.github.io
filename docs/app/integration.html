App / 09

Integrations

Export mitigations as tickets to Jira, Azure DevOps, or GitHub Issues. Receive status updates when tickets are closed and reflect them back in the risk model.

01

Supported Systems

  • Jira — project and issue type configurable, rich text description, custom fields
  • Azure DevOps — work item creation with area path and iteration
  • GitHub Issues — label mapping, milestone assignment
  • Polarion (planned)
02

Workflow

  • Select mitigations from the risk table and export as tickets
  • Ticket includes: threat description, risk level, proposed mitigation, verification criteria, DFD reference
  • Status sync: when ticket is closed, mitigation is marked implemented in TARAflow
  • Credential storage via system keychain (keytar) — no plaintext secrets in project files
