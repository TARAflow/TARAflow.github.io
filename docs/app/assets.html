Assets

Assets are the items of value in your system — data, functions, infrastructure, and physical components. Assigning CIANAAA protection goals to assets drives which STRIDE categories are generated for linked elements.

01

Asset Groups

Data

Data Assets

Configurations, firmware images, cryptographic keys, process parameters, user credentials.

Function

Function Assets

Control logic, safety functions, service availability, processing capability.

System

System Assets

Embedded controller, gateway, server — the platform as a whole.

Physical

Physical Assets

PCB, enclosure, cable routing — subject to physical attack vectors.

Service

Service Assets

Cloud services, APIs, communication infrastructure.

Process

Process Assets

Business processes, operational procedures, maintenance workflows.

02

CIANAAA Protection Goals

  • Confidentiality → Spoofing (S), Information Disclosure (I)
  • Integrity → Tampering (T)
  • Availability → Denial of Service (D)
  • Non-repudiation → Repudiation (R)
  • Authenticity → Spoofing (S), Elevation (E)
  • Authorization → Elevation (E)
  • Auditability → Repudiation (R)
  • Only active goals (level ≠ none) contribute to threat generation
